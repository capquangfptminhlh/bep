# Bếp Á Âu — full website prototype

Website tập trung **dự án bếp công nghiệp + sửa chữa/bảo trì**, không bán lẻ.

## Có sẵn
- Trang chủ
- Dự án
- Sửa chữa - bảo trì
- Giới thiệu
- Tin tức / kiến thức
- Liên hệ
- 6 bài viết dài, mỗi bài có cover + ảnh minh họa
- Desktop/mobile responsive
- Scroll reveal, parallax, hover motion, counter animation
- Chuyển trang có loader logo ở giữa
- sitemap.xml + robots.txt

## Lưu ý production
Thông tin pháp nhân, địa chỉ, email, vùng phục vụ, số liệu thành tích và form backend phải được xác minh/kết nối trước khi public chính thức.
